{{- /* Reader comments, stored as GitHub Discussions by giscus. One discussion per post, keyed by the post path. Readers sign in with their own GitHub account, so the site holds no accounts, no database and no tracking script. The giscus GitHub App must be installed on the repo named in [params.comments] or the box renders an error instead. The theme is a CSS file this site serves. giscus loads it inside its own iframe, which is the only way to restyle the widget. giscus has to fetch it over a public https URL, so only the production build points at it. Every other build, the dev server included, falls back to a built-in theme name. Off switches, widest first: enable = false in [params.comments] turns it off site-wide comments: false in a post's front matter turns it off for that post sample: true on a post never gets a box */ -}} {{- $page := . -}} {{- $c := .Site.Params.comments | default dict -}} {{- if and $c.enable $c.repo (ne $page.Params.comments false) (not $page.Params.sample) }} {{- $theme := $c.devTheme | default "light" -}} {{- if and $c.themeUrl hugo.IsProduction }}{{ $theme = ($c.themeUrl | absURL) }}{{ end -}}
